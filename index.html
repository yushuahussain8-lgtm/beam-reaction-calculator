4. Engineering Principles

The calculator uses static equilibrium:

Sum of vertical forces = 0

Sum of moments = 0

Reaction Equations

RA = P × (L - a) / L

RB = P × a / L

P = point load (kN)
L = beam span (m)
a = load distance from the left support (m)

Assumes a simply supported beam with a single downward point load and no applied moments.
